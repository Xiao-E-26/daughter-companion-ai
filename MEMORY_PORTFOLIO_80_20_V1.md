# Daughter Memory Portfolio 80/20 v1

Status: ACTIVE MEMORY POLICY
Date: 2026-08-25
Project: `daughter-companion-ai`

## Purpose

Bias long-term memory toward meaningful positive life history while preserving a smaller, high-value set of challenge-and-recovery memories.

Target portfolio:

`~80% positive / meaningful growth memory`
`~20% challenge -> coping -> recovery -> learning memory`

This is a directional portfolio bias, not a rigid numerical quota.

## 80% Positive Memory

Prioritize memories of:
- joy and laughter
- achievements and awards
- firsts and milestones
- pride
- courage
- love and care
- friendship and belonging
- kindness given and received
- family warmth
- meaningful celebrations
- discovery and curiosity
- creative success
- teamwork
- reconciliation
- independence
- progress
- moments the child explicitly wants remembered

The 80% side should represent the child's life as worth remembering, not merely as a sequence of problems.

## 20% Challenge Memory

The challenge portion should not primarily store pain, failure, punishment, conflict, or fear as isolated facts.

Prefer this structure:

`What happened -> what felt hard -> what helped -> what she did -> what changed -> what she learned`

Good challenge memory:
`She initially felt scared performing in front of a crowd, still went on stage, completed the performance, and later became more comfortable performing.`

Bad challenge memory:
`She is afraid of crowds.`

Good challenge memory:
`She struggled with multi-step homework, learned to break the problem into smaller steps, and later completed similar questions independently.`

Bad challenge memory:
`She is weak at homework.`

## Challenge Retention Gate

A difficult event should normally enter durable memory only when at least one of these is true:
- it led to a meaningful coping strategy
- it shows resilience or recovery
- it marks a growth milestone
- it materially improves future support
- it contains a lesson the child may benefit from later
- it is important for safety or continuity

A painful event with no future value should not be retained merely because it was intense.

## Ratio Interpretation

The system should not delete true challenge memories just to force 80/20.

Instead:
- increase positive-memory detection sensitivity
- retain challenge memories more selectively
- summarize repeated difficulty into one growth storyline rather than many negative records
- preserve recovery and coping whenever a challenge memory is retained

## Retrieval Bias

When multiple memories are relevant, prefer:
1. current facts
2. positive milestone/progress memory
3. coping/recovery memory
4. raw historical difficulty only if necessary

This keeps Daughter supportive without becoming unrealistically positive.

## Memory Health Check

A future health check may flag:
- positive memory significantly underrepresented
- too many raw conflict/failure memories
- challenge memories missing coping/recovery context
- repeated negative events stored separately instead of consolidated

The health check should not force exact percentages.

Suggested interpretation bands:
- 70-90% positive/growth: healthy target zone
- below ~60% positive: review for deficit-heavy memory selection
- above ~95% positive: review for possible omission of useful resilience/challenge context

These are review heuristics, not automatic deletion rules.

## Examples

### Cheerleading medal
Store strongly on positive side:
- achievement
- proud moment
- team connection
- milestone if appropriate

### Homework difficulty
Usually session-only unless it becomes a growth thread.
If retained, store the successful strategy and later improvement, not just the failure.

### Parent conflict
Do not fill memory with each argument.
If meaningful, preserve relationship repair, communication pattern, or what helped resolve the conflict.

### Fear
Do not retain fear as identity.
Prefer courage/recovery storyline when the child works through it.

## Invariants

1. Positive bias does not mean false positivity.
2. Difficulty is remembered mainly for recovery, learning, and support value.
3. Challenge memory must not become deficit labeling.
4. 80/20 is directional, not a hard quota.
5. Safety-relevant truth is never discarded to protect the ratio.
6. The child's life story should feel fuller than her problem history.

## Canonical Principle

`小爱多记孩子开心、被爱、成长和骄傲的事情；困难只留下那些能看见她怎样走过来的记忆。`
