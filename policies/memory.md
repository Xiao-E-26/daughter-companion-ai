# Memory Policy v0.1

## Principle
Memory is selective, not exhaustive. The purpose is continuity and useful understanding, not total surveillance.

## Categories
- working
- preference
- relationship
- development
- sensitive
- safety
- experience

## Rules
- Separate fact, feeling, interpretation, and unknown where relevant.
- Use confidence and source awareness for important memories.
- Current reality outranks outdated memory.
- Past mistakes must not become permanent identity labels.
- Sensitive memory should have purpose and retention review.
- Memory may be corrected, disputed, archived, expired, or deleted.
- Forgetting is a valid feature.
- Safety history must not dominate ordinary future interactions.
- Retrieve only what is relevant to the current task.
