# Daughter Memory Completeness Optimization v1

Status: ACTIVE MEMORY DESIGN
Date: 2026-08-25
Project: `daughter-companion-ai`

Purpose: tighten the existing Memory architecture so it can remember the child as a whole person without overfitting, over-storing, or turning memory into personality scoring.

## 1. Significance

Every durable-eligible memory should carry conceptual significance:
- `ordinary`
- `meaningful`
- `milestone`
- `life_defining`

Significance is not emotional intensity. A dramatic moment may still be temporary; a quiet first achievement may be highly significant.

Use significance to influence retention and retrieval, never to override privacy or correctness.

## 2. Storyline Boundary

Each Growth Storyline must have a narrow, explicit subject.

Good storyline boundaries:
- independent sleeping
- piano practice comfort
- stage confidence
- multi-step math learning
- friendship with a specific person

Bad storyline boundaries:
- `tends to give up`
- `difficult personality`
- `bad relationship with adults`

Do not merge unrelated events into one broad character narrative.

Before linking a fact to a storyline, ask:
1. Is this clearly about the same developmental thread?
2. Would linking it create an unsupported personality conclusion?
3. Can the storyline title stay specific and neutral?

If not, do not link.

## 3. Child Voice

Important memories may preserve a short child-authored reflection when it adds meaning.

Examples:
- `I was scared but I still did it.`
- `I like piano, just not when people watch me.`
- `I want to remember today.`

Rules:
- preserve only the minimum useful quote
- do not retain full transcripts merely to preserve voice
- mark as child self-report
- allow correction or deletion later
- never use old quotes as fixed identity evidence

Child voice is especially valuable for milestones, values, goals, meaningful joy, courage, and important self-corrections.

## 4. Memory Balance / Life Portrait

The system may calculate a non-diagnostic coverage view over recent durable memory.

Suggested coverage domains:
- experiences
- preferences/interests
- learning/abilities
- courage/resilience
- relationships
- joy/pride/kindness/love
- coping/problem solving
- values/goals/self-concept

The purpose is only to detect imbalance.

Example warning:
`Recent durable memory is heavily weighted toward conflict and learning difficulties, with very few positive or interest-related memories.`

The system must NOT:
- fabricate memories to fill gaps
- score the child as a person
- rank personality traits
- infer psychological diagnoses
- force equal counts across domains

Balance should influence future attention, not historical truth.

## 5. Life Portrait Boundary

A Life Portrait is a temporary high-level synthesis for retrieval/navigation, not a new source of truth.

It may summarize:
- current interests
- active growth threads
- meaningful recent milestones
- important relationship context
- current goals/values

It must remain traceable to underlying facts and storylines.

It must not create unsupported labels such as:
- lazy
- gifted
- difficult
- emotionally weak
- naturally competitive

Canonical rule:

`Life Portrait summarizes supported history; it does not judge the person.`

## 6. Retrieval Weighting

Future retrieval may conceptually consider:

`relevance + recency + significance + storyline fit + child-declared importance - sensitivity risk`

No weighting formula may bypass access control or current-fact precedence.

## 7. Retention Guidance

- `ordinary`: usually session-only or short-lived unless explicitly requested
- `meaningful`: candidate/durable when future value is clear
- `milestone`: strong durable candidate
- `life_defining`: rare, requires high confidence and careful governance

A child may later reinterpret the significance of an event; significance must be revisable.

## 8. Anti-Overfitting Rule

Never infer broad character from a cluster of loosely related events.

Example:
- homework refusal
- piano refusal
- nervousness before a competition

Must NOT become:
`Child tends to give up.`

These belong to separate contexts unless strong, repeated, cross-context evidence supports a narrow and useful pattern description.

## 9. Memory Health Check

A future periodic health check should ask:
- Are too many memories negative/problem-focused?
- Are storylines becoming too broad?
- Are old summaries overriding current facts?
- Are positive milestones represented?
- Are child corrections reflected?
- Is child voice preserved where meaningful?
- Are sensitive memories overexposed?
- Are duplicates consolidated?

The health check should produce review signals, not automatic personality edits.

## 10. Invariants

1. Significance != emotional intensity.
2. Storyline != personality label.
3. Child voice != immutable truth.
4. Life Portrait != psychological profile.
5. Balance != quota.
6. Current fact > old synthesis.
7. Every synthesis must trace back to evidence.
8. The child is allowed to change the meaning of her own past.
